# qa-artifacts — Folder README Templates

> The stlc-init-workspace skill writes one README.md per folder using the content below.
> Do not edit this file directly — edit the per-folder content and re-run the skill.

---

## requirements/README.md

```markdown
# requirements/

Place your requirement `.md` files here before starting the STLC pipeline.

Each file should describe one or more features using:
- User stories ("As a … I want … so that …")
- Acceptance criteria (numbered list or Given/When/Then)
- Out-of-scope statements (optional but recommended)

**Next step:** Run the `stlc-requirements-analyst` skill to analyse these files.
```

## qa-artifacts/4-execution-results/screenshots/README.md

```markdown
# screenshots/

Browser screenshots captured during test execution.

Naming convention: `TC-XXX-[pass|fail]-stepN.png`

Examples:
- TC-001-pass-step4.png  — TC-001 passed; screenshot after final step
- TC-002-fail-step3.png  — TC-002 failed at step 3
- TC-003-blocked.png     — TC-003 could not be started
```

- **`stlc-manual-executor`** reads `qa-artifacts/base-test/execute.env.md` at the start of every execution run to resolve the base URL, login credentials, and test data references.
